# ✨ Seshagiri Prasanna — Developer Portfolio

A creative and interactive personal portfolio built with React, Vite, and Framer Motion.

This portfolio showcases my projects, skills, and personality through smooth animations, aesthetic UI design, dark mode, doodle-inspired visuals, and a fully functional contact system powered by EmailJS.

---

## 🌟 Features

- 🎨 Pinterest-inspired UI with doodle aesthetics
- 🌙 Light / Dark mode toggle
- ✨ Smooth animations using Framer Motion
- 📱 Fully responsive design
- 📩 Functional contact form with EmailJS
- 💙 Interactive “Say Hello” feature
- ⚡ Fast Vite-powered performance
- 🎯 Modern and clean developer portfolio layout

---

## 🛠️ Tech Stack

- React.js
- Vite
- Framer Motion
- EmailJS
- JavaScript
- HTML5
- CSS3
